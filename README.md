# Vegetarische Rezept Sammlung

Willkommen in der **Vegetarischen Rezept Sammlung**! Diese Webanwendung ermöglicht es Benutzern, ihre Lieblingsrezepte zu teilen, zu bewerten und zu kommentieren. Egal, ob Sie ein erfahrener Koch sind oder gerade erst anfangen, hier finden Sie eine Vielzahl an leckeren, vegetarischen Rezepten.

## Funktionen
- Rezepte hinzufügen und verwalten
- Rezepte bewerten und kommentieren
- Suche nach Rezepten nach verschiedenen Kategorien
- Benutzerprofil zur Verwaltung Ihrer eigenen Rezepte

## Technologien
- **Frontend:** React.js, CSS, Redux
- **Backend:** Node.js, Express.js
- **Datenbank:** MongoDB
- **API:** RESTful API für die Rezeptverwaltung

## Installation
1. Klonen Sie das Repository: `git clone <repo-url>`
2. Installieren Sie die Abhängigkeiten für das Backend:
   ```bash
   cd backend
   npm install
   ```
3. Installieren Sie die Abhängigkeiten für das Frontend:
   ```bash
   cd frontend
   npm install
   ```
4. Starten Sie den Server:
   ```bash
   npm start
   ```
